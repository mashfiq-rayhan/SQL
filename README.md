# SQL : I always enjoy SQL 🗄️

SQL Master is a comprehensive workspace of SQL projects and hands-on exercises. The folder structure is organized by topic and complexity, starting from data definition and table management to advanced topics like normalization, relationships, transactions, aggregate functions, and built-in SQL operators. This workspace includes examples and solutions for both MySQL and PostgreSQL.

## ✨ Features

- 📚 Step-by-step SQL scripts for learning and practicing DDL, DML, and advanced queries
- 🏗️ Real-world table designs and data modeling for users, memberships, sales, bookings, and more
- 🔑 Deep dives into primary keys, foreign keys, and relational integrity
- 🔄 Data normalization, splitting, and joining data across multiple tables
- 📊 Grouping, aggregation, and analytical queries
- 🛠️ Usage of built-in SQL functions and operators for strings, numbers, and dates
- 🔒 Transaction management and ACID principles
- 🗂️ Modular folder structure for easy navigation and focused learning

- 🏆 Designed and implemented normalized relational schemas with robust primary and foreign key constraints
- 🔗 Demonstrated complex JOIN operations and data relationships across multiple tables

## 🗂️ Project Structure

- **04 - Data Definition & Managing Tables**: Creating databases, tables, and working with data types
- **05 - Data Manipulation & Querying**: CRUD operations and basic data queries
- **06 - Data Normalization & Relationships**: Splitting data, creating relationships, and JOIN operations
- **07 - More On Primary & Foreign Keys**: Advanced key constraints and relational integrity
- **08 - Grouping & Aggregate Functions**: GROUP BY, aggregate queries, and analytical functions
- **09 - Built-in Query Functions & Operators**: String, numeric, and date functions, plus advanced operators
- **10 - Database Transactions**: Transaction management, ACID properties, and practical transaction scripts
